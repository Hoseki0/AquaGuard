Hardware Pin Mapping

ESP32 wiring & voltage topology

🔋

12V Power Rail

12V Battery → Buck Converter → 5V DC to ESP32 Vin & Relay VCC. Common GND required on all components.

🚰

Solenoid (CH 1)

ESP32 GPIO 26 → Relay IN1. 12V(+) → Relay COM → NO → Solenoid. Install 1N4007 flyback diode.

⚡

Drain Pump (CH 2)

ESP32 GPIO 27 → Relay IN2. 12V(+) → Relay COM → NO → Pump. Install flyback protection diode.

📡

Depth Sensor

Signal → ESP32 GPIO 36 (VP). VCC → ESP32 3.3V. GND → Common Ground.
